# PC 区域下钻

## 入口与行为

地块详情的「区域 / 农户统计」打开完整层级及区域、小地块、农户汇总表。树节点和表格「进入」可以选择节点；地图下方面包屑可以返回父节点。地图边界点击的问题见下方已知问题。

「健康与巡检报告」位于地图顶部控制栏，在「巡飞节点 / 日期」右侧。底图尚未就绪时，入口仍保留在顶部。

- 通过 `ext_attrs.drilldown` 或 `sub-plots` 中的区域节点判断区域下钻主地块。
- 直接进入小地块时不请求上级地块、子地块树和整体统计。服务端负责最终权限校验。
- 每个范围的 summary、trees、tree/detail、timeline、健康和报告统一传当前节点 ID；整体统计始终使用已授权主地块 ID。
- 切换范围保留当前巡飞批次；若新范围时间线没有该批次则选择最新批次。
- scoped 批次始终重新请求 summary；仅 completed 底图可显示。pending、processing、failed、null 都不回退基础图、不请求树点。
- 底图和统计先显示，树点继续加载，30 秒超时后显示刷新入口。普通地块原有 8 秒加载策略与批次预取保持不变。
- 管理人员进入小地块时，采用服务端返回的所属区域底图，高亮当前小地块边界、弱化相邻边界。农户使用服务端裁切的小地块底图。
- 未检测病虫害/产量时隐藏相应批次指标、筛选、单树字段和统计列。下钻页面不展示旧组件中的固定健康/土壤示例值；真实数据在「健康与巡检报告」。
- 业务或 HTTP 403 提示后返回地块列表，不自动重试。

## 兼容边界

普通林地、工厂、仓库继续使用原有瓦片及面板流程。详情页支持字符串地块 ID 和旧的名称路由；地图入口传递 ID 的问题见下方已知问题。本次没有新增小程序专属页面，也没有加入管理后台导入或账号绑定功能。

## 已知问题（Review 确认，尚未修复）

- `RegionDetailMap.goToPlotDetail` 的弹窗快照遗漏 `id`，实际仍使用名称路由；跨区域同名小地块可能被匹配到另一地块。
- 地图边界的 `pointerdown` 被拖拽逻辑捕获，真实鼠标点击不能触发下钻。树节点和表格入口可用。
- 当前 14 项自动化测试未覆盖上述两种入口交互，测试通过不代表它们已修复。

## 验证

```sh
npm run test:drilldown
npm run lint -- --no-fix
npm run build:prod
```

`tests/fixtures/drilldown-browser.js` 可在隔离浏览器上下文中作为首次导航的 init script 注入本地开发页。它只允许 localhost，拦截 fetch 的 API 请求，并记录到 `window.__calls`；不能用于真实用户浏览器上下文。节点 900 为管理主地块，902 为农户小地块，800/801/802 分别为普通林地/工厂/仓库。`window.__fixture` 可切换底图状态、403 和响应延迟；报告导出和任务创建均为模拟响应。

本次验证（2026-11-07）：

- 单元回归覆盖业务错误、长 ID、无可用底图、随机图层刷新、普通缓存/会话隔离、层级分组、边界投影、农户入口。
- 模拟浏览器覆盖管理下钻、批次保留、慢请求覆盖保护、农户等待/失败/完成状态、403 返回、报告传参、防重复创建及普通林地/工厂/仓库。
- 使用用户提供的账号实测主地块 1053：13 个区域、41 个小地块、38 个农户。下钻至区域 1054、小地块 1067，确认底图仍属于区域 1054，当前范围 87 株，边界高亮与单树来源一致，健康/认证接口使用 1067。
- 实测普通林地 1001：基础底图、3 个巡飞节点和树点正常。
- 真实环境未提交农事任务；PDF 生成和任务创建的交互/传参通过模拟接口验证。未获得农户专用账号，农户界面与错误处理使用隔离模拟验证。

## 主要文件

- `src/modules/plot/drilldownMixin.js`：层级发现、范围与批次切换、过期响应保护。
- `src/modules/plot/services/drilldownService.js`：接口错误处理、层级分组。
- `src/modules/plot/services/plotBoundaryProjection.js`：按底图元数据投影边界。
- `src/modules/plot/components/DrilldownPanel.vue`：下钻树及统计表。
- `src/modules/plot/components/PlotScopeReport.vue`：当前范围健康、认证、巡检报告与农事操作。
